# Examples

Runnable examples of driving the Evidence Compiler live here.

Phase 1A ships no example scripts yet — the golden-fixture repo under
`tests/fixtures/golden-repo/` plus the CLI quickstart in the top-level
[README](../README.md) cover the end-to-end flow. This directory is a
placeholder for worked examples (custom collectors, per-repo config recipes,
adapter wiring) added in later roadmap phases.
